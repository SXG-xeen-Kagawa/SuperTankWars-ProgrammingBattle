# SXG2026版からの変更点・ルール補足

最終更新：2026年10月9日

SXG2026版での主な変更点と、戦車制作に関するルールの補足をまとめています。
すでに戦車を制作している方も、内容を確認してください。

## 🧭 ステージから離れた戦車への対策

ステージから離れすぎた戦車を、ステージ中央（原点）に向かって弾く仕様を追加しました。
上空などに留まり続けて戦闘を避けることへの対策です。

## 🛡️ 多数砲塔構成の防御調整

砲塔を10基以上登録した戦車では、出撃時に各砲塔を15%の確率で抽選し、選ばれた砲塔を砲弾が通過するようになります。

抽選は砲塔ごとに行うため、選ばれる砲塔数は一定ではありません。
再出撃時にも再抽選します。
この調整で、地面との接触や旋回・射撃機能は無効になりません。

## 🛠️ 装甲破壊後の質量計算の修正

装甲が壊れた際に、戦車が想定以上に軽くなる不具合を修正しました。
破壊されて外れた部品に応じて質量が減少するようになります。
質量の基本的な計算式は変更していません。

## 📐 戦車制作ルールの補足

参加者からの問い合わせを踏まえ、次のルールを明文化します。

- 回転部位には公式の回転パーツを使用してください。任意のオブジェクトにRotJointPartを追加して使用することは禁止です。
- 回転部位のスケール変更は禁止です。
- 公式の回転パーツを多数配置することは可能です。ただし、回転部位は壊れなくても砲弾を遮りません。
- 砲塔を同じ位置に重ねて配置することは可能です。ただし、10基以上登録した場合は前述の防御調整が適用されます。

## ✅ 更新後の確認のお願い

更新後のUnityプロジェクトで、制作した戦車の動作を再確認してください。
特に、装甲破壊後の挙動や、多数砲塔構成での防御を確認してください。
